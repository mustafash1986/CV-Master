# CV Servant | خادم التوظيف الذكي
**نظام محلي ذكي لأتمتة التقديم على وظائف العمارة والـ BIM للمهندس مصطفى محمود شوقي**

---

## 🌟 الميزات الرئيسية للبرنامج

1. **الذكاء الاصطناعي المحلي الفائق (100% Offline & Private):**
   - يعتمد على أحدث وأذكى نموذج محلي على جهازك: **`Qwen 3.5 (9B)`** عبر Ollama مع تسريع كامل على كارت الشاشة (GPU).
   - نموذج الرؤية البصرية: **`Qwen 3-VL (8B)`**.
2. **محرك قراءة الصور ثنائي النواة (Dual-Engine Arabic & English OCR):**
   - يدعم قراءة إعلانات الوظائف المصممة كصور وبوستات (المشهورة في الخليج على لينكدإن ومجموعات الواتساب الهندسية).
   - يستخدم محرك **Windows Media OCR الأصلي للغة العربية (`ar-SA`) والإنجليزية (`en-US`)** بدقة وسرعة فائقة، مع نموذج الرؤية البصرية.
3. **فلترة وفحص الكفالة (Visa Sponsorship Detector):**
   - مخصص للدول المستهدفة:
     - **أستراليا:** فحص تأشيرات الكفالة (TSS 482 / Subclass 186 / Relocation Assistance).
     - **كندا:** فحص تأشيرات الكفالة وموافقات الـ LMIA.
     - **نيوزيلاند:** فحص اعتماد جهة العمل (Accredited Employer Work Visa - AEWV).
     - **السعودية:** فحص نقل الكفالة وتأشيرات العمل الفورية.
     - **الكويت:** فحص تحويل الإقامة مادة 18.
4. **محرك تفصيل الـ ATS التلقائي (ATS Resume & Cover Letter Tailor):**
   - يقوم بتعديل الملخص المهني وترتيب المهارات وإبراز المشاريع المتوافقة مع متطلبات الوظيفة (مثل مشاريع الرعاية الصحية KUHSC، الأبراج وناطحات السحاب، أتمتة الريفيت عبر بايثون ودينامو).
   - يولد ملفين احترافيين متوافقين 100% مع برامج الفرز الآلي: **PDF** عبر ReportLab و **Word (.docx)**.
   - يصيغ خطاب تقديم (Cover Letter) مخصص باسم الشركة والمشروع.
5. **إدارة التقديم الذكية:**
   - **في حال وجود إيميل:** يجهز مسودة إيميل احترافية مع المرفقات ويرسلها عبر بريدك: `arch.mustafa.mahmoud.2007@gmail.com`.
   - **في حال التقديم عبر موقع أو لينكدإن:** ينشئ مجلداً منظماً باسم الشركة والوظيفة يحتوي على الـ CV المخصص، خطاب التقديم، وملف Dossier يحتوي على جميع الإجابات المطلوبة لنماذج التقديم.
6. **سجل ومتابعة الإكسيل والمزامنة السحابية (Excel Tracker & Google Drive Sync):**
   - يسجل كل وظيفة مع تاريخ الرصد، الشركة، الدولة، الكفالة، والحالة.
   - يقوم بمزامنة الإكسيل وحزم التقديم تلقائياً إلى Google Drive.
   - يحتوي على فاحص آلي للبريد الوارد (Inbox Checker) للتعرف على الردود وتحديث حالة الوظيفة تلقائياً إلى (`Interview`, `Rejected`, `Under Review`).
7. **التحكم والإشعار التفاعلي من الهاتف (Mobile Remote Control):**
   - إمكانية إرسال إعلان الوظيفة أو صورته من هاتفك إلى بوت تليجرام خاص بك.
   - يقوم البرنامج بتجهيز كل شيء وإرسال إشعار للموبايل يحتوي على ملخص الوظيفة وملف الـ CV مع زرين تفاعليين:
     - `[ ✅ موافقة وإرسال الإيميل فوراً ]`
     - `[ 📁 حفظ كملف تقديم يدوي فقط ]`

## 🚀 كيفية تشغيل البرنامج

يمكنك تشغيل البرنامج بضغطة زر واحدة عبر:
- النقر المزدوج على ملف: **`Launch_CV_Servant.bat`**
- أو عبر سطر الأوامر:
  ```bash
  python run_app.py
  ```

## ⚙️ إعدادات الحسابات والربط (ملف `.env`)

لربط الإيميل والموبايل بالكامل، انسخ ملف `.env.example` إلى `.env` وضع القيم التالية:

1. **إيميل الجيميل (Gmail App Password):**
   - ادخل إلى [Google App Passwords](https://myaccount.google.com/apppasswords).
   - أنشئ كلمة مرور تطبيق باسم `CV Servant` وضعها في:
     ```env
     GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx
     ```
2. **بوت تليجرام للموبايل (Telegram Bot):**
   - افتح تطبيق تليجرام وابحث عن `@BotFather` وأرسل `/newbot` للحصول على الـ `Token`.
   - احصل على رقم الـ `Chat ID` الخاص بك عبر محادثة `@userinfobot`.
   - أضفهما في ملف `.env`:
     ```env
     TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
     TELEGRAM_CHAT_ID=123456789
     ```
3. **مجلد Google Drive:**
   - إذا كنت تستخدم تطبيق Google Drive على ويندوز، يمكنك توجيه مسار المجلد مباشرة:
     ```env
     GDRIVE_INBOX_DIR=G:\My Drive\CV_Servant_Inbox
     GDRIVE_ARCHIVE_DIR=G:\My Drive\CV_Servant_Archive
     ```
